A PRAIA

COMO SE LÊ

A cor é só do veredicto: o mar, a nota e a régua usam a mesma escala. As linhas brancas a correr são o vento; as linhas curvas a entrar são as frentes de onda, dobradas pela profundidade. Os rumos a irradiar do largo marcam de onde o vento é bom para esta praia. Relevo exagerado ×1,5. Isóbatas aproximadas (modelo global, ~1 km, suavizado até à costa): servem para ler a praia, não para navegar.
